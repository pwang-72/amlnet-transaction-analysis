# Original AMLNet v2 Dataset

1. Download `AMLNet_v2_transactions.csv` from the [AMLNet v2 dataset on Zenodo](https://doi.org/10.5281/zenodo.21237971).
2. Rename the file to `transactions.csv`.
3. Place it in this directory (`data/raw/`).

For the complete data preparation and analysis workflow, see [Reproduction](../../README.md#reproduction) in the main README.
